# Course Management System (C + SQLite)

A console-based Course Management System developed in C using SQLite.

## Features

### Teacher
- Add Course
- Edit Course
- Delete Course
- Add Lessons
- Edit Lessons
- View Enrolled Students

### Student
- View Courses
- Search Courses
- Enroll in Courses
- View Lessons
- Track Lesson Progress

## Technologies
- C Programming Language
- SQLite Database
- Modular Programming

## Project Structure

- src/
- include/
- database/
- build/
